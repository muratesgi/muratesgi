## Operating Principles

- **Systems over isolated tasks** — repeated work should become a process, workflow or product.
- **Revenue over vanity metrics** — growth systems should connect activity to measurable business outcomes.
- **Data over assumptions** — decisions should be grounded in real operational and behavioral data whenever possible.
- **Automation with judgment** — automate repeatable execution while retaining human review where context and risk matter.
- **Build for scale** — systems should become easier to operate as complexity grows, not harder.
- **Strategy + implementation** — useful strategy must translate into reliable execution.
